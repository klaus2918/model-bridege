Model-Gate exe 架构图（v2.7.0 · Python 版）— 图例与说明

历史文档：本图描述 Python 版（pywebview 窗口 + WebView2）架构，仅用于对照 Python 回退版 dist\Model-Gate-python.exe。2.19 起默认产品为 Rust 版（托盘常驻 + 系统浏览器面板，进程树无 msedgewebview2），见 docs/architecture/rust-desktop-shell.md；配置模型见 docs/architecture/upstream-config-model.md。

本图为 dist\Model-Gate-v2.7.exe（PyInstaller 单文件）的运行架构：桌面壳 + 本地代理 + 协议适配 + 用量数据库，全部在一个进程内。

交付与构建

  • 打包：ModelGate.v27.spec（onefile、console=False、内嵌 modelgate/web 资源、图标 assets\ModelGate.ico）
  • 构建链：build.bat：版本读取 → 图标生成 → 有界测试门禁 → PyInstaller →（可选）Inno Setup 安装包
  • 运行形态：绿色版，配置写 bridge.config.json、数据写 exe 同目录 data\（modelgate.db / modelgate.log）

模块与源码对应

  • entry.py / modelgate/__main__.py — 打包入口与命令行解析、配置装载、单实例守卫、崩溃兜底
  • modelgate/app.py — pywebview 窗口、pystray 托盘、代理线程编排、降级策略
  • modelgate/proxy.py — HTTP 服务与路由、Bridge 内核、故障切换、TTFT、用量落库
  • modelgate/api.py — 控制面 REST（/api/*）：配置读写与重载、用量统计与导出、模型目录、上游探测、日志
  • modelgate/db.py — SQLite（WAL）明细与 settings、迁移与聚合（percentile 等）
  • modelgate/config.py — 配置优先级（文件优先）、密钥解析、上游归一化、热重载
  • modelgate/protocols/ — anthropic / openai / commandcode 三套协议适配与 thinking 回传缓存
  • modelgate/single.py / util.py / pricing.py — 单实例互斥体、日志/崩溃落盘、费用估算
  • modelgate/web/ — 面板前端（概览 / 模型 / 配置 / 用量 / 日志 5 页签）

关键行为要点

  • 故障切换只发生在「尚未向客户端写出任何字节」的区间（连接失败 / 5xx / 429），候补上限 2 个；URL 前缀强制时不切换。
  • TTFT 由上游首行到达时刻计时（流式有效，非流式为 0）；每请求一行写入 usage_records，含费用估算。
  • 配置以文件为契约、SQLite 快照只补缺；改密钥可用面板「重新载入」热生效，不重绑端口。
  • 明文密钥只驻内存；API 面板仅绑定 127.0.0.1，不对外暴露。
