# Model-Gate 控制台 v4 · 展示与交互重构方案

> 状态：已确认（2026-10-31）。v4 是唯一控制台入口，`/ui/` 不再提供 v3 回退。
> 输入：线上 `/ui/`（9 视图版）、线上 `/ui/classic`（完整旧面板）、`ui/v3.*`（12 视图开发版）、Rust 路由与配置模型。

## 1. 功能盘面（设计必须覆盖）

| 业务域 | 能力 | 关键约束 |
|---|---|---|
| 总览 | 网关健康、接入健康、今日 KPI、最近请求、待处理、快速开始 | 30 秒内回答“是否正常、哪里有问题、下一步做什么” |
| 接入编排 | 官方模板、自定义、免费来源、账号池、插件接入；详情、探测、密钥写入、删除 | 密钥只写不回显；删除需确认 |
| 模型与定价 | 模型目录、来源（白名单/目录拉取/套餐门槛）、别名、上游映射、逐模型 Key、单价与汇率、历史费用重算、JSON 编辑 | 单价匹配优先级：上游固定 > 任意上游；精确 > 通配 |
| 路由 | 默认路由、路由组（有序成员、失败切换）、统一入口 `/unified/v1`、命名分组 `/unified/{组}/v1`、可见上游白名单 | 401/403/404/普通 400 不切换；分组只影响统一入口 |
| 凭据池 | 池、成员、优先级、轮换、冷却、配额、失败阈值、探测；ZCode 账号池 | 池成员密钥脱敏；冷却状态可解释 |
| 资源 | 插件安装/启停/接入/解绑；免费来源探测与接入；官方模板 | 安装只登记；接入才创建上游 |
| 观测 | 用量 KPI/趋势/构成/耗时/上游/模型/会话/请求明细/导出/保留清理；提示词列表/详情/会话演进/diff/工具评估；运行日志；统一诊断 | 提示词默认脱敏、不记录响应；日志从文件尾部读取 |
| 设置 | 服务与全局、隐私默认、提示词记录、AI 配置接口、统一入口、路由组、模板、高级维护（JSON/备份/校验/诊断导出/更新） | 配置文件是唯一事实源；保存前备份；revision 冲突校验 |
| AI 接口 | manifest/schema/templates/inspect/plan/apply/audit/settings | 只读 + 草案 + 人工确认；密钥永不返回 |
| 更新 | 检查、下载、安装、下载目录、打开位置 | 安装需确认；版本与渠道可见 |

## 2. 现状问题（设计要解决的）

1. 导航 12 项、5 组，粒度不一致；“模型与定价”“路由组”“免费来源”“ZCode”相互割裂。
2. 总览信息密度高但没有明确焦点；KPI、表格、快速开始、待处理平铺。
3. 设置是一页 8 张卡的超长表单；保存语义和危险操作边界不清。
4. 观测页 4 张宽表叠加，列数 10–12，必须横向滚动；缺少“先结论后明细”的层次。
5. 接入详情抽屉只有接入页可用；模型、请求、提示词、日志没有统一的详情范式。
6. 状态表达分散（密钥缺失、池冷却、插件未接入、单价缺失、提示词未开启），没有全局待处理入口。
7. 表格缺少密度切换、列配置、批量操作；空态/错误态多为“暂无数据”。
8. 跨页跳转弱：从用量看不到对应接入详情，从模型看不到定价入口。

## 3. 信息架构 v4（按关注度 × 使用频率分层）

| 层级 | 页面 | 使用频率 | 设计策略 |
|---|---|---|---|
| P0 | 总览 | 每次打开 | 30 秒给出结论、异常和下一步 |
| P1 | 用量分析 | 每日 / 每周 | 一级入口，先结论后明细 |
| P1 | 提示词 | 每日 / 每周 | 一级入口，审查与演进并重 |
| P1 | 接入管理 | 新增或排障时 | 一级入口，统一列表 + 抽屉 |
| P2 | 日志与诊断 | 出问题时 | 一级入口，只读排障 |
| P3 | 配置中心 | 初始化 / 变更时 | 低频聚合，任务板 + 子页 |

```
Model-Gate
├─ 工作台
│  └─ 总览
├─ 分析
│  ├─ 用量分析
│  └─ 提示词
├─ 运行
│  ├─ 接入管理（官方 / 自定义 / 免费 / 账号 / 插件统一列表）
│  └─ 日志与诊断
└─ 配置
   └─ 配置中心
      ├─ 模型与路由
      │  ├─ 模型目录
      │  ├─ 单价表
      │  ├─ 统一入口
      │  └─ 路由组
      ├─ 凭据池
      │  ├─ 密钥池
      │  └─ ZCode 账号
      ├─ 资源库
      │  ├─ 插件
      │  ├─ 免费来源
      │  └─ 模板
      └─ 设置
         ├─ 服务与全局
         ├─ 隐私与记录
         ├─ AI 配置接口
         └─ 高级维护
```

- **一级导航 6 项 / 4 组**：高频页面始终 1 次点击可达；配置类功能不再分散在一级导航。
- **配置中心是任务板，不是表单堆**：首屏按「模型与路由 / 凭据池 / 资源库 / 设置」四张域卡片展示状态、待处理项和常用动作；进入子页后使用左侧二级导航。
- **总览只暴露行动**：待处理项直接深链到具体配置任务，例如 `#/config/credentials?focus=pool-zcode`、`#/config/models?tab=pricing&model=qwen3-max`。
- 总览首屏增加「用量快照」和「提示词审查」两张直达卡；顶栏全局搜索（⌘K）可直接跳转用量筛选与提示词详情。
- 任何对象（接入、池成员、模型、请求、提示词、插件、账号）都通过右侧详情抽屉打开，不跳整页。
- URL 可深链：`#/access/{id}`、`#/config/models?tab=pricing`、`#/usage?range=7d&upstream=xxx`、`#/prompts/{id}`、`#/config/credentials?focus=pool-zcode`。
- 全局搜索/命令面板（⌘K）覆盖页面、接入、模型、配置任务与动作。

## 4. 页面规格

### 4.1 总览

- 顶部状态带：运行状态、监听地址、版本、运行时长、最近刷新；右侧“连通性自检”。
- 4 个 KPI：今日请求、成功率、Token、估算费用；每个带 7 日 sparkline 与环比。
- 主栅格 8/4：
  - 左：流量趋势（24h / 7d / 30d 切换，请求/Token/错误三选一）；接入健康表（名称、类型、状态、今日请求、成功率、P95、操作）；最近请求 6 行（时间、模型、上游、状态、耗时、Token）。
  - 右：需要处理（按严重度排序，带“去处理”）；**用量快照**（今日 Token/费用/环比 + 迷你趋势，一键进入用量分析）；**提示词审查**（最近 24h 记录数、异常/敏感拦截数，一键进入提示词）；新手三步（仅在无接入或未完成时出现）。
- 规则：异常接入置顶；KPI 与快照卡可点击跳到对应用量筛选；空系统显示三步引导而非空表；点击最近请求行打开请求抽屉。

### 4.2 接入管理

- 顶部：标题、说明、`连通性自检`、`+ 添加接入`。
- 工具栏：搜索、来源分段筛选（全部/官方/自定义/免费/账号/插件）、健康筛选、排序、密度、列配置、列表/卡片切换。
- 表格列：接入（图标+名称+标签+默认星标）、类型、协议/地址（等宽、截断、复制）、模型（数量+别名数）、凭据（已配置/池 n/m/缺失/无需）、健康（点+P95）、今日（请求+成功率）、操作（测试/更多）。
- 批量选择后出现浮动操作条：启用、禁用、测试、导出、删除。
- 行点击打开 560px 详情抽屉，6 个页签：概览、连接、凭据、模型、高级、诊断；底部固定：测试连接、保存、删除。
- 空态：三步引导 + 添加第一个接入。

### 4.3 添加接入向导（880×640 模态）

1. 选择来源：官方厂商、自定义/中转、免费来源、账号池、插件；官方模板网格支持搜索与最近使用。
2. 填写配置：官方只填 Key + 标识；自定义 5 项（标识、名称、Base URL、协议、Key）；高级折叠（模型、别名、逐模型 Key、隐私、超时）。
3. 验证完成：显示接入摘要、探测阶段（DNS/TLS/HTTP/模型）、结果与修复建议；`完成` / `再添加一个`。
- 密钥输入只写，粘贴后仅显示掩码；关闭时若有未保存改动需确认。

### 4.4 模型与路由

四个页签共享顶部作用域（上游筛选、搜索）。

- **模型目录**：KPI（模型数、已定价、未定价、别名数）；表格列：模型、上游、来源、别名、单价、今日调用、状态；行操作“定价 / 设默认 / 查看接入”。
- **单价表**：左侧条目表（可内联编辑输入/输出/缓存价），右侧 360px 编辑面板（新增/编辑、计费类型、币种、标签、官方模板）；顶部汇率与“保存后重算历史费用”；JSON 编辑放入右侧抽屉。
- **统一入口**：可见上游矩阵（每行上游 + 开关 + 统一模型数）；分组卡片（名称、标识、成员 chips、端点复制）；未保存改动提示。
- **路由组**：组卡片 + 成员有序列表（拖拽手柄、上移/下移、移除）；右侧“生效预览”输入模型名，显示尝试顺序与不切换规则。

### 4.5 凭据池

- 顶部摘要：池数、密钥数、冷却中、配额耗尽。
- 池卡片 2 列：名称/标签、绑定上游、策略、可用成员条、今日请求、平均延迟、异常；展开显示成员表（优先级、掩码、状态、配额、冷却至、最近错误、启用开关）。
- 新建池模态：名称、标签、策略（优先级/轮询）、失败阈值、冷却时长、成员添加。
- 成员详情抽屉：状态时间线、最近使用、错误、配额、操作（重置冷却/禁用/删除）。
- `ZCode 账号` 页签：状态摘要、配置折叠、账号表、领取预览/立即领取/OAuth 流程、领取记录；危险操作独立区。
- 密钥只显示掩码；替换需重新输入。

### 4.6 资源库

- **插件**：卡片网格（图标、名称、版本、类型、能力标签、绑定接入数、状态）；操作：启用/禁用、接入、解绑、卸载；安装本地插件为拖拽/选择文件模态；顶部固定说明“安装只登记，接入才创建上游”。
- **免费来源**：来源卡片（风险等级、配额说明、探测状态、模型可用数）；模型表（状态、上下文、思考档位、延迟、拒因、建议、接入）；“全部探测”带进度与限流退避说明。
- **模板**：表格（模板 ID、厂商、协议、默认地址、模型、隐私能力、更新时间）；操作：查看、用于添加接入、导出。

### 4.7 用量分析（一级页面）

- 顶部粘性作用域条：时间范围（今日/昨日/24h/3d/7d/30d/全部/自定义）、上游、模型、会话、币种、自动刷新、导出 CSV/JSON、清除筛选。
- 5 个 KPI：请求数、总 Token、成功率、估算费用、P95 耗时；每个带环比。
- 图表区：趋势（折线/柱状切换，请求/Token/错误三选一）+ 分布（上游/模型/状态）。
- 二级 Tab：上游、模型、会话、请求；表格默认列 ≤ 8，其余进列配置；点击行打开详情抽屉。
- 请求抽屉：时序瀑布（排队/首 Token/生成）、Token 与费用、重试链、错误、脱敏请求头、会话跳转。
- 页头快捷：`查看提示词演进`、`打开日志`、`导出当前筛选`。

### 4.8 提示词（一级页面）

- 未开启记录时整页引导：说明记录范围、脱敏规则、保留策略，主按钮“去设置开启”。
- 列表：时间、会话、模型、消息数、字符数、预览；顶部时间/模型/会话筛选与内容搜索。
- 详情抽屉：消息树（system/user/assistant/tool）、角色过滤、长文本折叠、原始 JSON、下载。
- 会话演进：左侧请求时间轴，右侧差异对照（基准/对比、上一处/下一处、仅看差异）。
- 工具执行评估：调用/未匹配/重复/结果字符表 + 复制 Markdown 报告。
- 危险操作独立：清空、回收空间，均二次确认。

### 4.9 日志与诊断（一级页面）

- 顶部 Tab：运行日志 | 诊断。
- 日志：级别、搜索、行数、自动刷新、复制、清空、跳到末尾；等宽视图，级别着色，换行开关。
- 诊断：按严重度分组的检查项（配置、接入、凭据、价格、插件），每项含证据、影响、修复动作、复制诊断；顶部“重新检查”和“导出诊断”。

### 4.10 配置中心

- **任务板首页**：顶部一句话说明“低频配置集中在这里，日常操作请从总览或接入管理进入”；搜索框；四张域卡片：
  - 模型与路由：模型总数、未定价数、统一入口状态、路由组数，主行动“去定价 / 管理入口”。
  - 凭据池：池数、密钥数、冷却中、配额耗尽，主行动“查看冷却成员”。
  - 资源库：插件数、未接入插件、免费来源可用模型、模板更新，主行动“处理插件接入”。
  - 设置：上次保存时间、revision、待重启项、提示词记录状态，主行动“继续上次修改”。
- **常用任务**：添加接入、创建凭据池、配置统一入口、开启提示词记录、导出诊断；每项一行，带预计耗时。
- **最近变更**：按时间列出配置审计记录（谁、改了什么、revision、可回滚）。
- **子页**：左侧二级导航（模型与路由 / 凭据池 / 资源库 / 设置），右侧内容；顶部保留面包屑和“返回任务板”。
- **保存**：表单页固定底部保存条；未保存/保存中/已保存/保存失败；显示 diff 数量。
- **高级维护**：原始 JSON 抽屉、备份列表与恢复、配置校验、诊断导出、检查更新；危险操作二次确认（输入名称）。
- 端口变更提示“需重启”；保存前备份默认开启。

## 5. 交互规范

| 场景 | 规则 |
|---|---|
| 导航 | 侧栏 9 项分 4 组；当前项左侧 2px 信号条 + 浅色底；高频页（总览/用量/提示词）始终 1 次点击可达 |
| 搜索 | 顶栏全局搜索占位“搜索接入、模型、页面… ⌘K”；输入即出命令面板 |
| 详情 | 统一右侧抽屉，宽度 560；`Esc` 关闭；有未保存改动时确认 |
| 表格 | 表头吸顶；排序三态；密度舒适/紧凑；列配置持久化；行悬停显示快捷操作 |
| 筛选 | 条件以 chips 展示并可单独移除；刷新页面保留（localStorage） |
| 保存 | 表单页固定底部保存条；失败保留输入并定位首个错误；revision 冲突提示“重新加载/覆盖” |
| 密钥 | 永不回显；只显示“已配置 · 来源”；替换需重新输入；复制按钮仅复制掩码 |
| 危险操作 | 二次确认；删除接入/池/插件需输入名称；默认保留凭据，可勾选同时清理 |
| 加载 | 骨架屏；超过 800ms 显示“仍在加载”；保留旧数据时显示“已过期”标记 |
| 空态 | 说明 + 主行动 + 次行动（如“从模板添加”“导入 JSON”） |
| 错误 | 行内 banner + 重试 + 复制诊断；不整页报错 |
| 快捷键 | `⌘K` 命令；`/` 聚焦搜索；`g o/u/p/a/m/c/r/l` 跳转总览/用量/提示词/接入/模型/凭据/资源/日志；`?` 快捷键表；`Esc` 关闭层 |
| 响应式 | ≥1440 三栏；1024–1439 两栏；<1024 侧栏折叠为图标；<768 表格转卡片、抽屉全屏 |
| 动效 | 页面 120ms 淡入；抽屉 180ms；仅“运行中”状态点呼吸；尊重 reduced-motion |

“**信号台 / Signal Desk**”：深墨绿底、信号绿主强调、细分隔线与等宽数据；用领域色区分功能域，但只用于图标底、图表和状态，不用大面积色块。避免玻璃拟态、紫蓝渐变、过度圆角。
