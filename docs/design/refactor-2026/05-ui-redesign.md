# 05 UI 信息架构与交互设计

> 对应原型：`prototype/index.html`。原型是设计稿，不是生产代码；所有数据为演示数据。

## 1. 现状诊断（对照 v2.28 截图与代码）

| # | 问题 | 证据 | 影响 |
|---|---|---|---|
| 1 | 首屏同时放 6 个 KPI、上游表、接入信息、本地路径 | `index.html` 概览区 | 视线无焦点 |
| 2 | "模型"是独立一级页签，但模型目录属于接入 | 导航 | 概念割裂 |
| 3 | 上游编辑在"配置"页内联展开，字段 20+ 全暴露 | `app.js` `renderUpstreamCfgTable` | 官方厂商也被高级项淹没 |
| 4 | 预设选择只是下拉，选了仍要面对长表单 | `profileAccess` | 没有"只填 Key"的路径 |
| 5 | 免费来源、ZCode 各占一级页签，接入动作割裂 | 导航 | 无法统一启停/排障 |
| 6 | 用量、提示词、日志三页都含表格/筛选，重复 | 导航 | 学习成本高 |
| 7 | 概览上游表与配置页上游卡重复 | 两处 | 信息不同步 |
| 8 | 密钥来源有 env/file/agent/store/逐模型五种写法 | 配置模型 | 用户不知道选哪个 |
| 9 | 诊断散落在各页，没有统一"待处理" | 多处 hint | 出问题不知道去哪看 |
| 10 | 没有空状态引导与快速开始 | 首次使用 | 新用户懵 |

## 2. 新信息架构

```
Model-Gate
├─ 工作台
│  └─ 总览                健康、待处理、今日流量、快速开始
├─ 接入
│  ├─ 全部接入            列表/卡片、筛选、搜索、快速添加
│  ├─ 模型目录            声明/拉取/别名/定价（原"模型"页）
│  └─ 路由组              默认、分组、统一入口可见性
├─ 资源
│  ├─ 凭据池              单 Key、池、ZCode 账号（原 ZCode 账号）
│  └─ 插件                已安装、市场、接入动作
├─ 观测
│  ├─ 流量                用量图表 + 请求日志（原"用量"+"日志"）
│  └─ 提示词              记录、会话、差异（原"提示词"）
├─ 设置
│  ├─ 全局                端口、默认模型、超时、隐私默认
│  ├─ 模板                官方/自定义/插件模板
│  ├─ AI 配置             开关、权限、审计
│  └─ 高级                原始 JSON、备份、诊断导出
```

一级功能域 7 个：**总览 / 接入 / 凭据 / 插件 / 流量 / 观测 / 设置**；侧栏按 工作台 / 接入 / 资源 / 观测 / 设置 5 个分区组织，接入域含 全部接入 / 模型目录 / 路由组 3 个子页。原"模型"进接入子页，原"免费来源"和"ZCode"进接入/凭据，原"日志"和"用量"合并为流量，原"提示词"进观测。

## 3. 页面规格

### 3.1 总览

**目标**：30 秒内回答"网关是否正常、哪个接入有问题、下一步做什么"。

```
┌ 左栏（主） ───────────────────────────────┬ 右栏（320） ──────────┐
│ 状态条：运行中 · 127.0.0.1:8900 · 4h15m   │ 快速开始             │
│ 今日：请求 1,284 · Token 9.2M · 失败 3     │ ① 添加官方厂商       │
│                                            │ ② 接入插件           │
│ 接入健康（列表，不是 KPI 卡堆）             │ ③ 配置 AI 助手       │
│  ● DeepSeek   官方  ok   420ms  128 次     │                      │
│  ● 我的中转   自定义 warn 1.2s   42 次     │ 待处理（3）          │
│  ● ZCode      账号池 ok   890ms  310 次    │ 池冷却 1             │
│  ...                                       │ 模板更新 1           │
│                                            │ 备份可恢复 1         │
│ 最近事件（时间线，默认 5 条）               │                      │
└────────────────────────────────────────────┴──────────────────────┘
```

规则：
- KPI 最多 4 个，且必须可点击跳转；
- 上游行点击打开详情抽屉，不跳页；
- 异常行置顶，带"修复"按钮；
- 无接入时显示三步引导，不显示空表。

### 3.2 接入（全部接入）

**列表视图**（默认）：

| 列 | 内容 |
|---|---|
| 接入 | 图标 + 名称 + 来源徽标（官方/自定义/免费/账号/插件） |
| 协议 | `openai` / `anthropic` / ... + 地址（hover 显示完整） |
| 模型 | 已声明数 / 已拉取数 |
| 凭据 | `单 Key` / `池 3/4` / `无需` / `待补充` |
| 健康 | 状态点 + 最近延迟 |
| 今日 | 请求数 + 失败数 |
| 操作 | 测试 / 编辑 / 更多 |

**卡片视图**：适合少量接入，显示同样的 6 个关键信息，不做大色块。

**工具栏**：搜索、来源筛选、状态筛选、排序、`+ 添加接入`（主按钮）、视图切换。

**添加接入**：打开模态，两个入口卡片：
- **官方厂商**（推荐）：厂商网格/搜索 → 填 Key → 完成；
- **自定义/中转**：5 项表单 → 完成；
- 底部：`从插件接入`、`从免费来源接入`。

### 3.3 快速添加（官方）

```
┌ 添加接入 ──────────────────────────────────────────┐
│ ① 选择厂商        ② 填写凭据        ③ 完成          │
│                                                    │
│ [搜索厂商…]                                        │
│ ┌ DeepSeek ┐ ┌ OpenAI ┐ ┌ Anthropic ┐ ┌ Kimi ┐     │
│ │ 官方     │ │ 官方   │ │ 官方      │ │ 官方 │     │
│ └──────────┘ └────────┘ └───────────┘ └──────┘     │
│ ┌ 智谱 ┐ ┌ MiniMax ┐ ┌ 通义 ┐ ┌ 更多… ┐           │
│                                                    │
│ 已选：DeepSeek 官方                                │
│ 协议 openai · 地址 api.deepseek.com · 模型自动拉取  │
│ 隐私 [✓] 请求 ZDR（该厂商支持请求级开关）           │
│                                                    │
│ [上一步]                              [下一步]      │
└────────────────────────────────────────────────────┘
```

第 ② 步：
- 标识（预填，可改）；
- Key 输入框（password，粘贴后只显示 `sk-****`）；
- 隐私开关（模板默认勾选，可改）；
- `高级设置` 折叠：模型、别名、超时、逐模型 Key、compat；
- 主按钮：`添加并测试`。

第 ③ 步：显示接入摘要、测试结果（成功/失败原因）、`完成` / `再添加一个`。

**自定义**：第 ① 步选"自定义/中转"，第 ② 步显示 5 项：标识、厂商、请求地址、协议、Key；协议默认 openai；地址旁有"常见示例"。

### 3.4 上游详情抽屉（右侧 560px）

```
[名称]  [官方] [openai]                    [测试] [更多]
────────────────────────────────────────────
概览
  地址  https://api.deepseek.com
  模型  12 个（已拉取）
  凭据  单 Key · 本机加密库 · 已配置
  隐私  ZDR 开 · 请求级 · [修改]
  今日  128 次 · 失败 0 · P95 820ms
────────────────────────────────────────────
[连接] [凭据] [模型] [高级] [诊断]     ← 子页签
连接：协议、地址、传输、超时、目录拉取
凭据：来源、写入/替换、逐模型 Key、池绑定
模型：声明/拉取、别名、模型覆盖
高级：compat、会话头、原始 JSON（折叠）
诊断：错误/警告列表 + 修复建议
```

编辑采用"就地编辑 + 保存条"，不用整页跳转；高级项默认折叠。

### 3.5 凭据

- 顶部池卡片：名称、绑定上游、策略、`3/4 可用`、今日请求、异常；
- 成员表：标签、类型、状态、优先级、冷却、配额、最近使用、操作；
- 添加成员：标签 + 密钥（password）+ 优先级 + 配额（可选）；
- 池设置：策略、冷却、失败阈值、是否允许回落单 Key；
- ZCode 账号：放在"账号池"子页签，保留领取/验证码入口，但不再占一级导航。

### 3.6 插件

- 已安装：卡片显示 kind/tier/版本/状态/绑定接入数；操作：接入、禁用、更新、卸载；
- 市场：官方/远程/本地三个来源；安装只登记，不自动接入；
- 插件详情：manifest 摘要、所需配置块、权限、隐私说明；
- 关键文案："安装不会修改你的配置；接入才会创建上游。"

### 3.7 流量

- 顶部：时间范围、上游、模型筛选；
- 图表：请求量/Token/失败率（三选一，不堆叠）；
- 表格：时间、上游、模型、状态、耗时、Token、费用；
- 行展开：请求摘要、错误、重试链；
- 日志作为"请求日志"子页签，保留实时刷新与清空。

### 3.8 观测

- 提示词：列表 + 详情 + 会话演进 + 差异（沿用现有能力）；
- 诊断：统一诊断列表（error/warn/info），按接入分组，支持"一键复制修复建议"；
- 默认只显示最近 24h 的 error/warn。

### 3.9 设置

分组卡片，不再一页长表单：

- 全局：监听地址/端口、默认模型、超时、模型缓存；
- 隐私默认：新接入默认 ZDR、默认 training；
- AI 配置：启用、允许 apply、允许池统计、审计查看；
- 模板：模板列表、版本、更新提示；
- 高级：原始 JSON 编辑（默认折叠）、备份与恢复、诊断导出。

## 4. 视觉规范

### 4.1 方向

"**精密控制台**"：深墨绿背景、信号绿强调、细网格与刻度线，信息密度高但不拥挤。避免紫色渐变、玻璃拟态、过多圆角卡片。

### 4.2 色彩

| Token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--bg` | `#0A0E0D` | `#F4F1E8` | 页面底色 |
| `--surface` | `#111715` | `#FBF9F3` | 卡片 |
| `--surface-2` | `#161E1B` | `#EFEBDF` | 次级表面 |
| `--line` | `#24302B` | `#D8D2C2` | 边框 |
| `--text` | `#E8EDE9` | `#1A211E` | 主文字 |
| `--muted` | `#8FA098` | `#5F6B64` | 次要文字 |
| `--signal` | `#7BE495` | `#1F7A4D` | 主强调/成功 |
| `--amber` | `#E5B567` | `#9A6414` | 警告 |
| `--danger` | `#F07167` | `#B3372F` | 错误 |
| `--info` | `#7CC7D9` | `#23697A` | 信息 |

状态点：ok=`--signal`，warn=`--amber`，error=`--danger`，idle=`--muted`。

### 4.3 字体

- 正文：`"IBM Plex Sans", "Noto Sans SC", sans-serif`
- 等宽/数字：`"IBM Plex Mono", "JetBrains Mono", monospace`
- 标题不额外用花体；靠字号、字重、字距建立层级。
- 数字统一 `font-variant-numeric: tabular-nums`。

### 4.4 间距与圆角

- 4px 基准；页面 padding 32；卡片 padding 20；表格行高 48。
- 圆角：卡片 10px、按钮 8px、徽标 4px、输入 8px。
- 阴影只用于抽屉/模态，不用多层浮夸阴影。

### 4.5 动效

- 页面切换 120ms 淡入；
- 抽屉 180ms 滑入；
- 状态点呼吸仅用于"运行中"，不做全屏动画；
- 尊重 `prefers-reduced-motion`。

## 5. 关键交互规则

| 场景 | 规则 |
|---|---|
| 保存 | 底部固定保存条，显示"未保存/保存中/已保存"；失败保留输入 |
| 密钥 | 输入后不可回显；只显示"已配置 · 本机加密库"；替换需重新输入 |
| 删除上游 | 二次确认，输入名称；默认保留凭据，提供"同时清理" |
| 测试连接 | 抽屉内异步，显示阶段（DNS/TLS/HTTP/模型）；失败给可操作建议 |
| 空状态 | 每个列表都有"下一步"按钮，不只显示"暂无数据" |
| 键盘 | `⌘K` 搜索接入；`Esc` 关抽屉；`N` 新建 |
| 错误 | 顶部 toast + 行内诊断；不弹全屏错误页 |
| 移动端 | <900px 侧栏收起为顶部下拉；表格转卡片 |

## 6. 组件清单

- `AppShell`：侧栏 + 顶栏 + 内容区
- `StatusDot` / `Badge` / `SourceBadge`
- `DataTable`（排序、筛选、空状态、行操作）
- `Drawer`（详情/编辑）
- `Modal`（快速添加）
- `Stepper`（三步向导）
- `Field`（label、help、error、password）
- `SecretInput`（只写、不可回显）
- `PrivacyToggle`（含能力说明）
- `DiagnosticList`
- `Toast`
- `ConfirmDanger`

## 7. 验收

- [ ] 一级导航 7 个，原 8 个页签的功能都能在新 IA 找到。
- [ ] 官方厂商从点击"添加接入"到完成 ≤ 3 次点击 + 1 次粘贴 Key。
- [ ] 自定义厂商默认只显示 5 个必填项。
- [ ] 任意上游详情 1 次点击可达，字段分组不超过 5 组。
- [ ] 密钥在任何页面都不可回显。
- [ ] 空状态、错误、加载、无权限四种状态都有设计。
- [ ] 深色/浅色主题对比度满足 WCAG AA（正文 ≥ 4.5:1）。
