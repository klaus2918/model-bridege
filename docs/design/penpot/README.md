# Model-Gate · Penpot 展示重构工作区

本目录保存 **Penpot 高保真展示稿** 的设计输入、令牌、连接设置与验收记录。
目标：把 `docs/design/refactor-2026/09-console-v4-design.md` 第 7 节的 18 块画板
在 Penpot 中完整落地，作为 Model-Gate 控制台 v4 的唯一展示稿。

## 1. Penpot 连接设置（项目内留存）

| 项 | 值 |
|---|---|
| MCP 服务名 | `penpot` |
| 传输 | Streamable HTTP |
| 地址 | `http://127.0.0.1:9001/mcp/stream` |
| 连接方式 | Penpot 打开目标文件 → 插件 `Penpot MCP` → 填入上述地址 → Connect |
| 前提 | 插件标签页保持打开；MCP 服务运行中；每次执行前用 `execute_code` 探活 |

探活代码：

```js
return { pages: penpotUtils.getPages(), page: penpot.currentPage?.name };
```

若返回 `No Penpot plugin instances are currently connected`，说明插件未连上，
不是 Penpot 文件问题。按上表重新连接即可。

## 4. 执行与验收

1. 探活 Penpot 插件；
2. 运行构建脚本生成 18 块画板；
3. 用 `export_shape` 导出每块画板 PNG，逐板核对：
   - 一级导航 6 项、4 组；
   - 配置能力全部收进配置中心；
   - 总览待处理项可深链；
   - 密钥不回显；
   - 表格默认列 ≤ 8；
   - 状态五态齐全；
   - 深/浅对比度 ≥ 4.5:1。
4. 把验收结果回写 `acceptance.md`。

## 5. 与现有展示稿的关系

`docs/design/refactor-2026/v4/` 是 HTML 展示稿（18 屏，可运行、可截图）。
Penpot 版本是它的**设计事实源**：后续视觉调整先改 Penpot，再同步回 HTML 展示稿。
